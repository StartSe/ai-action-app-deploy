# Entrelinhas

Achar numa pilha de PDFs a passagem que responde a uma dúvida leva horas, e a busca por palavra-chave não entende o que você quer dizer. Você pergunta em linguagem natural; o app lê cada linha do documento, mostra na própria página, destacado, onde a resposta está escrita e indica o quanto tem de confiança.

Arquivos de configuração desta solução, gerados automaticamente. O acesso e o passo a passo ficam disponíveis para quem participa do AI Action.
