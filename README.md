# Ata Executiva

A reunião acaba sem decisões e responsáveis registrados. Transcreve o áudio e gera a ata com ações, prazos e o e-mail de follow-up.

[![Publicar este app](https://img.shields.io/badge/Publicar%20este%20app-1f4fd8?style=for-the-badge)](https://render.com/deploy?repo=https://github.com/StartSe/ai-action-app-deploy/tree/deploy-reunioes-ia)


Imagem: `ghcr.io/startse/reunioes-ia:latest`

Opção avançada, rodar no seu computador (requer Docker):

```bash
docker run --rm -p 3008:10000 -v reunioes-ia-dados:/app/data ghcr.io/startse/reunioes-ia:latest
# depois abra http://localhost:3008
```

Depois de publicar, abra o app e clique em Configurações (`/setup`) para conectar a IA. Catálogo completo: https://startse.github.io/ai-action-app-deploy/
