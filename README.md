# Call Guiada

Na call de vendas, o cliente conta o que precisa e quem conduz tem que lembrar na hora qual serviço resolve e como explicar. Aprende o catálogo nos documentos da empresa, ensaia com clientes simulados e, durante a call no Zoom, mostra só para quem conduz o serviço certo, o argumento e a frase do cliente que justifica a sugestão.

Arquivos de configuração desta solução, gerados automaticamente. O acesso e o passo a passo ficam disponíveis para quem participa do AI Action.
