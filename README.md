# Busca Inteligente · AI Journey

A busca da loja procura só as palavras digitadas e não entende a intenção do cliente. O Jev lê a intenção, o orçamento e para quem é o presente e dá nota para cada produto, ao lado da busca comum.

Arquivos de configuração desta solução, gerados automaticamente. O acesso e o passo a passo ficam disponíveis para os participantes da StartSe.
