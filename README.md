# Leitura de Contratos

Decidir o que negociar antes de acionar o jurídico. Lê o PDF, pontua o risco e lista cláusulas críticas, prazos e o que está faltando.

[![Publicar este app](https://img.shields.io/badge/Publicar%20este%20app-1f4fd8?style=for-the-badge)](https://render.com/deploy?repo=https://github.com/StartSe/ai-action-app-deploy/tree/deploy-contratos-ia)


Imagem: `ghcr.io/startse/contratos-ia:latest`

Opção avançada, rodar no seu computador (requer Docker):

```bash
docker run --rm -p 3007:10000 -v contratos-ia-dados:/app/data ghcr.io/startse/contratos-ia:latest
# depois abra http://localhost:3007
```

Depois de publicar, abra o app e clique em Configurações (`/setup`) para conectar a IA. Catálogo completo: https://startse.github.io/ai-action-app-deploy/
