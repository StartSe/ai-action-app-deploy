# CRM que Se Preenche

O vendedor odeia preencher CRM, e o funil vira ficção. Escuta a reunião e propõe etapa, valor, concorrente e próximo passo, cada um com o trecho que sustenta — a pessoa revisa e confirma antes de aplicar.

[![Publicar este app](https://img.shields.io/badge/Publicar%20este%20app-1f4fd8?style=for-the-badge)](https://render.com/deploy?repo=https://github.com/StartSe/ai-action-app-deploy/tree/deploy-crm-que-se-preenche)

Imagem: `ghcr.io/startse/crm-que-se-preenche:latest`

Opção avançada, rodar no seu computador (requer Docker):

```bash
docker run --rm -p 3020:10000 -v crm-que-se-preenche-dados:/app/data ghcr.io/startse/crm-que-se-preenche:latest
# depois abra http://localhost:3020
```

Depois de publicar, abra o app e clique em Configurações (`/setup`) para conectar a IA. Catálogo completo: https://startse.github.io/ai-action-app-deploy/
