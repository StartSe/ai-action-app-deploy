# Custos de IA

O CFO não sabe quanto a empresa gasta com ferramentas de IA nem se está dentro do orçamento. Lê faturas de ferramentas de IA, compara o gasto contra o orçamento planejado e mostra o que estourou.

[![Publicar este app](https://img.shields.io/badge/Publicar%20este%20app-1f4fd8?style=for-the-badge)](https://render.com/deploy?repo=https://github.com/StartSe/ai-action-app-deploy/tree/deploy-custos-ia)


Imagem: `ghcr.io/startse/custos-ia:latest`

Opção avançada, rodar no seu computador (requer Docker):

```bash
docker run --rm -p 3014:10000 -v custos-ia-dados:/app/data ghcr.io/startse/custos-ia:latest
# depois abra http://localhost:3014
```

Depois de publicar, abra o app e clique em Configurações (`/setup`) para conectar a IA. Catálogo completo: https://startse.github.io/ai-action-app-deploy/
